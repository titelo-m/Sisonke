Community Guidelines

Sisonke works because neighbours trust each other. These guidelines keep it that way.

1. Be honest about your tools

List tools that are in working condition and describe any damage or wear honestly. If a tool has a fault, say so in the description. Borrowers make decisions based on what you tell them.

2. Return tools in the condition you received them

If a tool was returned to you clean and working, return it the same way. If something breaks during normal use, tell the owner immediately and work out a fair arrangement.

3. Honour the agreed dates

If you borrow a tool for a weekend, return it on the agreed day. If your plans change, message the owner early so they can plan around it.

4. Deposits are a security measure, not income

The deposit exists to protect the owner if a tool is lost or damaged. It should be reasonable and returned once the tool is returned in good condition.

5. Respect privacy and safety

Do not share another user's personal information outside of arranging a pickup. Meet in safe, public locations where possible. Report any user who behaves inappropriately.

6. No prohibited items

Sisonke is for household and garden tools only. Do not list weapons, power tools with modified safety features, or any item that is illegal to own or lend in South Africa.

7. Leave honest reviews

Reviews help the community decide who to trust. If a borrower or lender behaved badly, say so. If they were excellent, say that too. Reviews are how reputation is built.

8. Report problems

If something goes wrong — a tool is stolen, a user is abusive, or a listing is misleading — use the report feature. We act on every report. Repeat offenders are removed from Sisonke.

By creating an account, you agree to follow these guidelines. Sisonke may suspend or remove accounts that repeatedly break them.
